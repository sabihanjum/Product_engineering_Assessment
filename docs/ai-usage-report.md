## AI OUTPUT THAT WAS WRONG

The initial password hashing setup used Passlib with bcrypt. In the installed Python 3.13 environment, the bcrypt backend failed during password hashing because of an incompatibility. Also, frontend-only permission hiding would not have been sufficient to protect another student's tickets.

## HOW I IDENTIFIED THE PROBLEM

The backend test suite failed during test collection while creating the test user's password hash. I also reviewed the generated authorization flow against the security requirement that backend authorization must prevent Student A from accessing Student B's ticket.

## HOW I FIXED IT

I changed the password hashing scheme to Passlib's portable `pbkdf2_sha256` scheme and reran the API tests. I kept authorization checks in FastAPI so ticket listing, ticket detail access, comments, assignment, priority changes, and status changes are validated server-side. I also verified the frontend production build.
